## MVP APIs (4)

### 1. Get Stream URL
| Field | Value |
|-------|-------|
| **US** | US-STREAM-01, US-STREAM-02 |
| **Method** | GET |
| **Endpoint** | `/api/v1/stream/:episodeId` |
| **Operation ID** | `getStreamUrl` |
| **Auth** | Yes (JWT) |
| **Description** | Lấy signed URL để xem video streaming |

**Path Parameters**:
| Param | Type | Description |
|-------|------|-------------|
| episodeId | string | Episode ID |

**Request Headers**:
```
Authorization: Bearer {accessToken}
X-Device-ID: {deviceId}
```

**Response 200**:
```json
{
  "success": true,
  "data": {
    "streamUrl": "https://vz-xxx.b-cdn.net/video-guid/playlist.m3u8?token=xxx&expires=123",
    "episode": {
      "id": "string",
      "title": "Tập 5",
      "episodeNum": 5,
      "duration": 2700,
      "movie": {
        "id": "string",
        "title": "Phim ABC"
      }
    },
    "resumeAt": 1500,
    "watermark": {
      "text": "user@example.com | u123",
      "position": "random"
    },
    "nextEpisode": {
      "id": "string",
      "title": "Tập 6",
      "episodeNum": 6
    },
    "expiresAt": "ISO datetime"
  }
}
```

**Errors**:
| Code | HTTP | Message |
|------|------|---------|
| STREAM_EPISODE_NOT_FOUND | 404 | Tập phim không tồn tại |
| STREAM_NOT_READY | 400 | Video đang được xử lý |
| STREAM_SUBSCRIPTION_REQUIRED | 403 | Cần đăng ký Premium để xem nội dung này |
| STREAM_CONCURRENT_LIMIT | 429 | Bạn đang xem trên quá nhiều thiết bị |

**Business Logic**:
1. Validate JWT token
2. Get episode info, check if premium
3. If premium → check subscription status
4. Check concurrent streams (max 2 devices)
5. Register stream session in Redis
6. Generate signed URL with 4-hour TTL
7. Get resumeAt from watch_history
8. Return stream data with watermark info

**Notes**:
- X-Device-ID generated by frontend, stored in localStorage
- resumeAt từ watch_history nếu 5% < progress < 95%
- nextEpisode là tập tiếp theo (nếu có)

## Signed URL Algorithm

```typescript
function generateSignedUrl(videoId: string, userId: string): string {
  const tokenKey = process.env.BUNNY_STREAM_TOKEN_KEY;
  const pullZone = process.env.BUNNY_PULL_ZONE;
  const expiry = Math.floor(Date.now() / 1000) + (4 * 3600); // 4 hours

  // Create signature
  const hashableBase = `${tokenKey}${videoId}${expiry}`;
  const token = crypto
    .createHash('sha256')
    .update(hashableBase)
    .digest('base64')
    .replace(/\+/g, '-')
    .replace(/\//g, '_')
    .replace(/=+$/, '');

  return `https://${pullZone}.b-cdn.net/${videoId}/playlist.m3u8?token=${token}&expires=${expiry}`;
}
```

## Concurrent Stream Management

### Redis Data Structure
```
Key: streams:{userId}
Type: Hash
Fields:
  {deviceId}: {timestamp}
TTL: 60 seconds (auto-cleanup)

Example:
  streams:user123 = {
    "device_abc": "1706356800000",
    "device_xyz": "1706356790000"
  }
```

### Check Logic
```typescript
async function checkConcurrentLimit(userId: string, deviceId: string): Promise<boolean> {
  const key = `streams:${userId}`;

  // Get all active sessions
  const sessions = await redis.hgetall(key);

  // Clean expired sessions (timestamp > 60s ago)
  const now = Date.now();
  const activeSessions = Object.entries(sessions)
    .filter(([_, timestamp]) => now - parseInt(timestamp) < 60000);

  // Check if device already registered
  const existingDevice = activeSessions.find(([did, _]) => did === deviceId);
  if (existingDevice) return true;

  // Check limit
  if (activeSessions.length >= 2) return false;

  return true;
}
```

## Frontend Watermark Implementation

```typescript
// VideoWatermark.tsx
function VideoWatermark({ userId, email }: WatermarkProps) {
  const canvasRef = useRef<HTMLCanvasElement>(null);

  useEffect(() => {
    const drawWatermark = () => {
      const ctx = canvasRef.current?.getContext('2d');
      if (!ctx) return;

      // Random position (changes every 30s)
      const x = Math.random() * (canvas.width - 200);
      const y = Math.random() * (canvas.height - 50);

      ctx.globalAlpha = 0.3;
      ctx.font = '14px Arial';
      ctx.fillStyle = '#ffffff';
      ctx.fillText(email, x, y);
      ctx.fillText(`ID: ${userId.slice(0, 8)}`, x, y + 20);
    };

    drawWatermark();
    const interval = setInterval(drawWatermark, 30000);
    return () => clearInterval(interval);
  }, [userId, email]);

  return (
    <canvas
      ref={canvasRef}
      className="absolute inset-0 pointer-events-none z-10"
      style={{ mixBlendMode: 'difference' }}
    />
  );
}
```

## Device ID Generation

```typescript
// Frontend utility
function getOrCreateDeviceId(): string {
  const key = 'ms_device_id';
  let deviceId = localStorage.getItem(key);

  if (!deviceId) {
    deviceId = `${Date.now()}_${Math.random().toString(36).substr(2, 9)}`;
    localStorage.setItem(key, deviceId);
  }

  return deviceId;
}
```
